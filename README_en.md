**A multilingual personal portfolio reinterpreting Windows XP aesthetics for the modern web**
> I planned this portfolio to clearly showcase my unique style and growth process that would be difficult to convey through a traditional resume. By reinterpreting the familiar visual language of Windows XP for modern web, I expressed my identity through nested layouts that feel like a website within a website. Through responsive structure based on HTML·SCSS·JavaScript, multilingual content management, and filter/modal-centered interactions, users can quickly explore projects and understand my work intentions and learning records.

## Overview
### Background
In today's environment where countless designers and developers are active, having a space that clearly communicates individual identity and showcases one's work philosophy and strengths is crucial. I felt that existing resumes couldn't properly express 'me' and weren't sufficient for showing growth direction or work intentions.

<br/>

### Purpose
- Build a site that can organically showcase my work, way of thinking, and growth process as a developer.
- Beyond a simple portfolio, enable users to intuitively understand my tendencies and capabilities.

<br/>

### Keywords
`Windows XP`
- Designed to capture the feel of Windows XP, which was the first OS I encountered
- Particularly as I'm studying frontend development in 2025, designed it like a website within a website to represent 'me'
  
`Readability and Flow`
- Intuitively arranged information flow and content structure for comfortable user navigation

`Learning-Centered / Adaptability`
- Organically incorporates past learning and future direction

## Features
### Core Feature
`Multilingual Support`
- In my previous Studio Ghibli project, I used the inefficient method of creating new HTML files for each language.
- Therefore, in this project, I use objects in JS to make internal content management much easier.
  
`Filter Functionality`
- Based on values entered in objects, shows values that match button text.
- Filters are divided by project category and project technologies used, displaying corresponding items when buttons are clicked.
  
`Modal Popup`
- When projects are clicked, modals popup to minimize page navigation and enhance user convenience.

**Purpose**
- Enable users to recognize information more intuitively and use it conveniently.

**Summary**
- Projects can be viewed using filtering functionality by category and tools & technologies.
- Projects are arranged in 3 columns but switch to 1 column in responsive view.
   - Simple tags appear on project hover.
   - Modals popup on project click.
- Modals are divided into project overview on the left and project preview on the right.
   - Project overview includes a button to open a demo page with specified size in a new window.
   - Project overviews mainly describe study content or project background and changes in before/after format.
   - Project preview uses swiper to view project results as GIFs, with technology icons appearing at the bottom.
   - Bottom of project preview has buttons to navigate to project brief, design mockup, and GitHub for detailed project information.
