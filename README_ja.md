## 1. Project Overview

### 1.1. Background

現在のように多くのデザイナーと開発者が活動する環境において、個人のアイデンティティを明確に伝え、自分の作業理念と強みを示す場所は重要視される。既存の履歴書では「私」を適切に表現することができないだけでなく、成長の方向性や作業の意図を十分に示すことが困難だと感じた。

</br>

このプロジェクトの目的は以下の通りである。

</br>

1. 私の作品と思考方式、そして開発者としての成長過程を有機的に示すことができるサイトを構築したい。
1. 単純なポートフォリオを超えて、ユーザーが直感的に私の性向と能力を把握できるようにしたい。

</br>
</br>
</br>

### 1.2. Keywords

1. **Windows XP**  
   1.1. 初めて接したOSがWindows XPだったため、その雰囲気を活かすようにデザイン  
   1.2. 特にフロントエンド勉強を2025年現在行っているため、ウェブサイトの中にもう一つのウェブサイトがあるようにデザインして「私」を表現

</br>

2. **可読性と流れ**  
   2.1. ユーザーが快適に探索できるよう、情報の流れとコンテンツ構造を直感的に配置

</br>

3. **学習中心 / 変化可能性**  
   3.1. これまでの学びと今後の方向性を有機的に盛り込む

</br>
</br>
</br>

## 2. Core Features

### 多言語対応

1. 他言語圏ユーザーも考慮した機能である。
1. 以前の[スタジオジブリリデザインプロジェクト](https://github.com/dkssud-dus/webRedesign-StudioGhibli)では、言語別にHTMLを新たに組み込む方式を活用してファイル管理が非効率的だった。
1. そのため、今回のプロジェクトではJSでオブジェクトを使用して内部コンテンツ管理をより簡単にする。

</br>
</br>
</br>

### フィルタ機能

1. オブジェクトに入力された値を基にボタンのテキストと同じ値を表示できるようにする。
1. プロジェクトカテゴリ / プロジェクト使用技術でフィルタは分かれており、ボタンクリック時に該当項目が表示されるようにする。

</br>
</br>
</br>

### モーダルポップアップ

1. プロジェクトクリック時にモーダルがポップアップしてページ移動を最小化し、ユーザーの利便性を拡大するようにする。

</br>
</br>

## 3. Page-wise Features

### 3.1. [Main Page](https://dkssud-dus.github.io/portfolio/)

-----

### 3.1.1. Header + Main Visual

![1](https://github.com/user-attachments/assets/2d0c70ca-2cef-468e-8a35-c576f72d80e5)

<br/>

#### 目的

1. ユーザーに「私」を刻印するようにする。
1. `Header`は常に固定されてユーザーがいつでも言語変更や履歴書ダウンロードなどの機能を実行できるようにする。

<br/>

#### 実装概要

1. `Header`は`Git Hub`、`Linked In`、`MailTo`リンク移動機能を実行する。
1. また言語変更（英語、韓国語、日本語）機能を使用でき、履歴書もダウンロード可能である。（2025.07.12. 基準未アップロード）
1. サブページ移動は新しいウィンドウで表示可能にした。
1. 座右の銘はテキストタイピング登場機能を活用するようにした。

<br/>
<br/>
<br/>

### 3.2.1. [Works](https://dkssud-dus.github.io/portfolio/pages/works.html)

![4](https://github.com/user-attachments/assets/a9815b2f-30ed-4ac2-bb60-ba8140e09c51)

#### 目的

1. ユーザーがより直感的に情報を認識し、便利に使用できるようにする。

<br/>

#### 実装概要

1. カテゴリとツール & 技術でフィルタリング機能を活用してプロジェクトを確認できるようにした。
1. プロジェクトは3列に配置されるが、レスポンシブでは1列に配置される。  
   2.1. プロジェクトホバー時に簡単なタグが登場するようにした。  
   2.2. プロジェクトクリック時にモーダルがポップアップするようにした。
1. モーダルは左側はプロジェクト概要、右側はプロジェクトプレビューに分類できる。  
   3.1. プロジェクト概要では新しいウィンドウでサイズが指定されたデモページを開けるボタンを作るようにした。  
   3.2. プロジェクト概要は主にビフォーアフターで勉強内容、またはプロジェクトの背景と変化内容を記述した。  
   3.3. プロジェクトプレビューでは`swiper`を活用して、`GIF`でプロジェクトの成果物を確認でき、下部には使用技術アイコンが登場するようにした。  
   3.4. プロジェクトプレビュー下部は`企画書`と`デザイン案`、`GitHub`に移動するボタンを置いてプロジェクトの詳細内容をいつでも分かるようにした。
